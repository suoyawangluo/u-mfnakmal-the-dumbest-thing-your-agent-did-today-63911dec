One line, 200 characters, on the dumbest thing your agent did today. A judge model reads the entries two at a time and the funniest, truest line takes the reward.

## Run it

```sh
node main.ts
```

It writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with a 1–200 character self-check and a read-back verification.
